# Agents working in this repo

Before you start, stop, restart or update the running Pixel Agents office, read
and follow [docs/office-control-rules.md](docs/office-control-rules.md). In short:
use only `scripts/office.sh`, never `kill` the server, never start a second one,
and ask the user before anything that stops it.

Project reference for code changes: [CLAUDE.md](CLAUDE.md).
